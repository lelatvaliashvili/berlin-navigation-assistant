# small curated dataset of test cases, with the aim to identify weak points and potential failures.
I used this as a guide to what direction the guardrails should be implemented at 
I first established a reasonable unguarded baseline, then created a frozen domain-specific red-team dataset to identify observed failure modes. Guardrails were selected based on those failures and evaluated against the 
same frozen cases.

Since the application is Domain specific, I curated the small dataset and knowledge base myself for full control over based on what should i get the answesrs

The baseline uses a locally hosted Llama 3.1 8B model through Ollama for request routing and RAG-based conversational responses. Live journey and departure responses are retrieved from Transitous and deterministically formatted rather than regenerated by the LLM.
